# Questão 1 - Padrão Strategy (Web Search)

Este repositório contém a solução da Questão 1 da atividade de Padrões de Projetos Orientados a Objetos. O objetivo da atividade foi refatorar um mecanismo de busca simulado aplicando o **Padrão Strategy** para encapsular os filtros de consultas (`QueryFilter`).

## Documentação do Uso de IA

Para a resolução desta questão, a Inteligência Artificial (Gemini) foi utilizada como uma ferramenta de apoio guiado, fornecendo um tutorial passo a passo em vez da solução completa pronta.

### Prompts Utilizados

Durante o desenvolvimento, os seguintes prompts foram enviados à IA:

1. **Definição de Persona e Regras:** *"Gemini, aja como como um profissional de Padrões de Projetos Orientado a Objetos. Com isso, tenho uma atividade para ser feita... você entendeu? se sim me explique o que é para ser feito."*
2. **Solicitação do Passo a Passo (Questão 1):** *"primeira questão, monte um passo a passo de como eu resolvo isso: [Texto do Enunciado + Código Fonte de Main.java, Snooper.java e WebSearchModel.java]"*
